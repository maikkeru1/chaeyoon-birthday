# Chaeyoon Birthday 💕

A sweet interactive birthday website for Chaeyoon.

## How to open on phone (GitHub Pages)

1. Create a new repository on GitHub (e.g. `chaeyoon-birthday`)
2. Push this project:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/chaeyoon-birthday.git
   git push -u origin main
   ```
3. Go to **Settings → Pages → Build and deployment**
4. Set **Source** to `Deploy from a branch`
5. Choose branch `main` and folder `/ (root)`
6. Save — after ~1 minute your site will be live at:
   `https://YOUR_USERNAME.github.io/chaeyoon-birthday/`

Send that link to Chaeyoon — it works on any phone browser!

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`
